## Prerequisites

- [Order of the Sinking Star](https://store.steampowered.com/app/499170/Order_of_the_Sinking_Star/)
- [CrossOver](https://www.codeweavers.com/crossover)
- [Pi](https://pi.dev/)

## Quick start

1. Launch the game
2. Start the puzzle
3. Launch Pi in the repo folder
4. Tell it, "Please solve this one"
